TimeFixer

What can:

1) Connects to the Energosphere PC database, the data for which is taken from .txt, and receives a list of devices with a time different from the server time of 100+ seconds.
2) Record the current Time/Date for the following counter types:
 - NPO MIR(MIR C-04/05/07)
 - Mercury 203-234
 - NZIF
 - ART
 - SEB-2А.07

3) Perform time adjustment in steps not more than 900 seconds for KPZ (M2M) counters.
4) Retrieves host data from .txt for cyclic time correction for ART/SEB-2A/07 counters.

Что умеет:

1) Подключается к базе данных ПК «Энергосфера», данные для которой берутся из .txt, и получает список устройств со временем, отличным от времени сервера на 100+ секунд.
2) Записывает текущие время/дату для следующих типов счетчиков:
 - НПО МИР (МИР C-04/05/07)
 - Меркурий 203-234
 - НЗИФ
 - АРТ
 - СЭБ-2А.07

3) Для счетчиков КПЗ (M2M) корректировку времени выполняет шагами не более 900 секунд.
4) Получение данных хостов из .txt для циклической коррекции времени для счетчиков ART/SEB-2A/07.
